TS-MD は、Markdown の説明文と実行・型検査可能な TypeScript modules を同じ `.ts.md` document に記述するためのツール群です。

## 基本モデル

一つの `ts` または `tsx` コードフェンスを、一つの独立した ES module として扱います。

~~~markdown
# Example

```ts values
export const value = 42
```

```ts main
import { value } from ':values'
console.log(value)
```
~~~

- TypeScript コードフェンスには module 名が必要です
- module 名は document 内で一意です
- 同名コードフェンスは連結されません
- document を直接実行・importすると `main` module が使われます

## Module imports

```ts
import { value } from ':values'
import { start } from './app.ts.md'
import type { User } from './user.ts.md:types'
```

型検査、補完、Node.js実行、bundler integration、tangleはすべて同じmodule modelを使用します。
